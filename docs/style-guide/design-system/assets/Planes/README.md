# Planes

Top-down plane silhouettes on a 128px grid, nose up, with a 4px graphite outline and rule-300 blue for the folded underside.

- `scout-dart.svg`: the quick scout, a classic dart.
- `fighter-swift.svg`: the nimble fighter, swept wings and a sky-blue cockpit fold.
- `bomber-heavy.svg`: the heavy bomber, wide wings and a pencil-yellow payload.
- `crumpled.svg`: what's left after a hit. Use it on loss screens and in the kill feed.

The build menu and result screens now use the 3D renders in the Aircraft group. Keep these flat silhouettes for small, top-down uses: minimap markers, the kill feed and HUD indicators. Rotate them freely (they point up at 0°). `crumpled.svg` is still the loss-screen art.
