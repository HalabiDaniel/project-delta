# Buildings

PNG renders of every defence and building from the Model Lab, at every level, on a transparent background with the soft ground shadow and pencil edges. Trimmed to the model with 16px of padding; up to 768px on the long side.

File names are `<id>-level<n>.png` (levels 1 to 3), or `<id>.png` for a building with one level.

| Building | id | Levels |
| --- | --- | --- |
| Turret | `turret-assembly` | 1–3 |
| Rocket Launcher | `rocket-launcher` | 1–3 |
| Radar | `radar` | 1–3 |
| Workshop | `workshop` | 1–3 |
| Storage | `storage` | 1–3 |
| Command Center | `command-center` | 1–3 |
| Runway | `runway` | 1–3 |
| Helipad | `helipad` | 1 |
| Hangar | `hangar` | 1–3 |
| Ink Depot | `ink-depot` | 1–3 |

Show them with `object-fit: contain` on `desk-200` (the BuildSlot art well) or straight on paper. Never put text over them. The Runway is long and flat: give it a wide box. To re-render after a model changes, use the PNG set button in the Model Lab export copy.
