# Logos

The paperwars.io mark: a white paper plane, folded, flying up and to the right out of a pencil-yellow tile.

- `mark.svg`: the primary mark, pencil-400 tile, graphite outline. App icon, favicon, loading screen, social avatar.
- `mark-cardboard.svg`: the same on a cardboard-400 tile, for in-world signage and merch on light grounds where yellow would clash.
- `mark-glyph-graphite.svg`: the plane alone in graphite (#26242c), for single-colour use on Daylight paper.
- `mark-glyph-chalk.svg`: the plane alone in chalk (#f3efe4), for single-colour use on Lights out.

Rules: keep clear space of a quarter of the tile's width on every side; never recolour the tile outside these versions, rotate the plane, or add effects. The wordmark is live text, **paperwars.io** in Lilita One, all lowercase, in ink-900. Next to the mark, set it at the tile's height × 0.5 with a gap of `space-3`.
