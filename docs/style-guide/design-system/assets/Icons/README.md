# Icons

**Placeholder set.** Small UI icons are Lucide (see the brand book); these drawn icons stand in for large icons until the Synty Military HUD pack replaces them.

28 icons drawn as paper cut-outs: white or palette fills with a 2.5px graphite (#26242c) marker outline on a 48px grid. The white fill keeps them readable on both Daylight paper and Lights out chalkboard, so there is one set for both themes.

Show them with `<img class="pw-icon">` at 24px (default), `pw-icon--md` 32px or `pw-icon--lg` 48px. Below 24px the outline gets muddy; don't go smaller. Always give icon-only controls an accessible name.
