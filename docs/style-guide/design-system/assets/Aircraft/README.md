# Aircraft

PNG renders of all eleven planes from the Aircraft Lab, each in its three textures (`paper`, `cardboard`, `grey`), on a transparent background with the ground shadow. Trimmed with 16px of padding. File names are `<id>-<texture>.png`.

| Plane | Role | Inspired by |
| --- | --- | --- |
| Dart | Scout | SR-71, high-speed recon |
| Specter | Scout | RQ-4, surveillance drone |
| Swift | Fighter | F-16, basic fighter |
| Lightning | Fighter | F-35, stealth multirole |
| Raptor | Fighter | F-22, air superiority |
| Falcon | Fighter | Su-57, agile stealth fighter |
| Jumper | Fighter | AV-8B, VTOL fighter |
| Thug | Bomber | A-10, ground attack |
| Widewing | Bomber | B-52, heavy bomber |
| Lancer | Bomber | B-1B, supersonic bomber |
| Ghost | Bomber | B-2, stealth bomber |

The roles here are a starting split for the build menu; change them as the game balance settles. Paper is the default texture. In PlaneCard, the three textures are the small swatches next to the role.
