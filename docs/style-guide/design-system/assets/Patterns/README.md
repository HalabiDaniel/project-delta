# Patterns

Seamless background tiles. Use them with `background-image` and the tile's own size; never scale them.

- `ruled-paper.svg` (64 × 32): notebook rules at the `space-8` pitch on paper-100. Mission briefs, patch notes, the main menu.
- `chalkboard-ruled.svg` (64 × 32): the same rules for Lights out.
- `graph-paper.svg` (32 × 32): squared paper for the build grid and the base editor.
- `cardboard-corrugated.svg` (24 × 24): corrugated cardboard, for large cardboard surfaces such as the base editor's frame. Not behind text.
- `desk-wood.svg` (128 × 32): wood grain for the desk behind the paper, for empty states and loading screens.

Keep text on ruled and graph paper only; the cardboard and wood tiles are too busy for reading.
