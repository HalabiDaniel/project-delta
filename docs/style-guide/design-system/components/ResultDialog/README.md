# ResultDialog

The dialog after a flight: you either came home safe with a reward, or crumpled and lost what you put in.

`pw-result--win` and `pw-result--loss` colour the title; the art comes from the Planes group (the plane you flew, or `crumpled`). List every gain and loss as a row so the player sees exactly where the paper went, then give one primary action. The title is always short and exclaimed: "Home safe!", "Crumpled!".
