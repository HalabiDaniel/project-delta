# TeamChip

A player's team colour, name and desk number, for lobbies, the scoreboard and kill feed.

`pw-team__desk` gets one of `pw-t1` to `pw-t8`. Always show the desk number next to the colour, because some team colours are close in lightness. Mark the local player with `pw-team--you` and the `pw-team__you` label. The consumer provides the names and team order.
