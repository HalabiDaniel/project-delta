# CoachMark

A tutorial hint on a taped-on sticky note, written in the `doodle` style.

The note uses the softer `sticky-200` paper with a graphite outline and hard shadow, and tilts by 1.5 degrees. The dismiss button sits bottom-right: "Got it" in heavy uppercase with a Lucide `check` after it. Use it for one-off tips in the first sessions and for "psst" hints about the match ("their radar is down!"). Keep it to one or two sentences, never put numbers players need or controls inside the note text, and show one at a time.
