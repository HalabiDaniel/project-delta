# Badge

A small marker-outlined tag for status on cards, slots and players.

Variants: `pw-badge--new` (eraser pink, for things the player hasn't opened yet), `pw-badge--level` (pencil, `Lv 1` to `Lv 3`), `pw-badge--locked` (with the Lucide `lock` icon), `pw-badge--enemy` (raid red) and the plain paper default for neutral facts like a desk number. Keep the text to one or two words.
