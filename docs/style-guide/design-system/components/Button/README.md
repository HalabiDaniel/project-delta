# Button

A pencil-yellow, marker-outlined button that drops 2px when pressed.

Use `pw-btn` with one of `pw-btn--primary` (the one main action on a screen), `pw-btn--secondary` or `pw-btn--danger` (abandon, scrap, leave). Add `pw-btn__cost` to show the paper price inside a build button. When the player can't afford it, set `disabled` and say what's missing: "Need 80 more paper". Minimum height is 44px for touch and controller. The consumer provides the label and click handling.
