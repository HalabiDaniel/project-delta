# Tabs

Segmented tabs that sit in a sunken desk tray, for the build menu and other top-level sections.

The selected tab is a sheet of paper lifted out of the tray (`aria-selected="true"`). Every tab has a Lucide icon before its uppercase label: `plane` for Planes, `shield` for Defences, `factory` for Buildings, `map` for Missions. An optional `pw-tab__count` shows how many items are inside. Use 2 to 5 tabs. On a controller, the shoulder buttons move between tabs.
