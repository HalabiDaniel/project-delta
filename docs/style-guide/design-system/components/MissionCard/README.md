# MissionCard

A mission brief on a notebook page: plain paper with the red margin line and a thick outline.

The header has a Lucide icon for the mission type: `eye` for scout, `bomb` for bomb, `swords` for dogfight, `shield` for defend. Every card says what to do in one sentence, then what you win and what you risk: winnings read `trophy` +300 `files` (paper) in green, and the risk names the plane you'd lose, with a `plane` icon, in red. The footer has the target desk and a Take off button.
